## Краткое описание исправлений

Референс содержит 14 классов противоречий. Главные:

1. **Габаритная цепь.** Полки 610 и дверь 614 шире стороны 600 габарита 1800×700×600. Разрешение: 700 — фасад, 600 — глубина; внутренний проём 620×520 (стойки 40×40 по углам); полки пересчитаны в **608**, дверь — **608×1712**, зазоры 6 мм (с учётом ЛКП и допусков).
2. **Профиль стойки описан тремя способами** (труба 40×40×2 / уголок L40×40×2 / П-профиль) и ещё 80×40×2 в формулировке задания. Принят **гнутый П-профиль 40×40×2** с перфорацией 10×10, шаг 25 мм — только он совместим с габаритами и даёт базу под обшивку и полкодержатели.
3. **Полки «висят в воздухе»**: на референсе нет кронштейнов и отверстий под них. Решение — кронштейны **120×140×2 по 2 шт на полку**, винт М6 + квадратная гайка в отверстия стоек.
4. **Г-образная труба показана 1 шт.** на замкнутую раму; стык со стойками не проработан. Решение — **2 зеркальные Г-детали 620×520**, сварка «в ус» + косынки 40×40×3, стык к стойкам через приварные пластины 50×50×3.
5. **Перфорация теряется между видами** (задняя площадка верхней полки на рендере глухая; 2 vs 3 зоны жалюзи на стенке; дверь только в карточке). Введена единая система перфорации (Ø6/30×30 на полках, жалюзи 30×5/25, «капля» 8×15 на двери).
6. **Не описаны крышка и задняя стенка** — добавлены; задняя стенка работает диафрагмой жёсткости.
7. **Высотная цепь 1800 не замкнута** — принято: опоры 40 + стойки 1720 + верхняя рама 40 = 1800; уровни полок (450 / 900–1000 / 1350–1430) привязаны крепежом к шагу отверстий 25 мм.

## Принятые допущения (кратко)

- **Материалы:** лист 08пс/Ст3сп (ГОСТ 19904); труба 40×40×2 (ГОСТ 8645).
- **Толщины:** стойки и рама 2 мм; полки 1,5 мм (расчёт прогиба при 80 кг: без отгибов f ≈ 37 мм — недопустимо, с отгибами 30 f < 1,5 мм); обшивка и дверь 1 мм; монтажная пластина 3 мм.
- **Перфорация:** полки Ø6 шаг 30×30; стойки квадрат 10×10 шаг 25; дверь «капля» 8×15 шаг 40; боковины — жалюзи 30×5 шаг 25, две зоны.
- **Крепёж:** каркас — сварка MIG/MAG; полки/обшивка — винт М6 + квадратная гайка (разборка, регулировка по высоте); обшивка к раме — заклёпки вытяжные 4×8.
- **Гибка:** R = t, **К-фактор 0,44** (нейтральный слый при R/t ≈ 1), уточнение пробной гибкой; допуски ±0,5.
- **Покрытие:** порошковая окраска RAL 7035, 60–80 мкм.

## 3D-модель (готовый результат) — `3D-модель/`

Технологическая сборка КШ-02 построена параметрически и прошла через **КОМПАС-3D v25** (импорт STEP → нативный .a3d → экспорт). Структура — по узлам производства: **01 Каркас сварной** (стойки П-40×40×2 ×4, Г-образные трубы 620×520 ×2, пятки, поперечина) → **02 Обшивка** (крышка, задняя стенка, боковины) → **03 Дверь** (полотно, петли ×3, ручка-замок) → **04 Полки и полкодержатели** (3 полки + кронштейны ×8) → **05 Монтажная пластина** (пластина + втулки ×4). Всего **36 деталей**, перфорация (стойки 10×10/25, полки Ø6/30, дверь Ø8) — для FEA-проверок.

| Файл | Формат | Назначение |
|---|---|---|
| `КШ-02.000_сборка.x_t` | **Parasolid** | **формат для SolidWorks**: ядро SW = Parasolid, открывается `Файл→Открыть` как родная сборка → `Сохранить как .sldasm/.sldprt` (2 клика) |
| `КШ-02.000_сборка.a3d` | КОМПАС-3D v25 | нативная сборка КОМПАС (дерево с именами и обозначениями) |
| `КШ-02.000_сборка_AP242.stp` | STEP AP242 | универсальный обмен (36 твёрдых тел, 42 продукта сборки) |
| `КШ-02.000_сборка.stp` | STEP AP214 | исходная развёртка из параметрической сборки (FreeCAD) |
| `КШ-02.000_сборка.FCStd` | FreeCAD | редактируемый источник (параметрическая генерация) |
| `manifest.json` | — | ведомость тел: имена, объёмы, габаритные рамки |
| `КШ-02_модель_в_КОМПАС.png` | — | документ открыт в КОМПАС-3D v25 (дерево сборки) |

**Почему не .sldasm/.sldprt:** SolidWorks на компьютере не установлен (только eDrawings/Composer/Electrical/Inspection), а КОМПАС-3D v25 формат SolidWorks **только читает** (`ksConverterFromSW`), но не пишет — проверено через API КОМПАСа (`Export sldasm → False`). Parasolid .x_t — ближайший эквивалент: SolidWorks открывает его нативно (это его родное ядро) и сохраняет в свой формат без потерь.

**Пайплайн сборки:** FreeCAD 1.1 (параметрическая генерация 36 тел по размерам заключения) → STEP → **КОМПАС-3D v25** (KsAPI: `ConvertFromAdditionFormat` → `SaveAs .a3d` → `ConvertToAdditionFormat` → .x_t / STEP AP242). Проверка: 36 `MANIFOLD_SOLID_BREP` в AP242, имена узлов сохранены.

## Экспорт в SolidWorks (кратко)

STEP AP242 — основной формат (сохраняет дерево сборки, имена, цвета, атрибуты); Parasolid (.x_t) — контрольный (родное ядро SolidWorks, геометрия без трансляции); DXF развёрток слоями CUT/BEND/HOLES/MARK — производственный эталон. Листовые детали в SW конвертируются командой «Вставить гибы» с тем же K = 0,44.
